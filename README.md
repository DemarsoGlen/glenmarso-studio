# Glen Marso Studio

Студия литературно-философского творчества.

**Сайт:** [studio.glenmarso.com](https://studio.glenmarso.com)

## О проекте

Авангардный минималистичный сайт студии.  
Цветовая гамма: чёрный / белый / синий.  
Формы — острые геометрические осколки.

## Структура

- `index.html` — главная страница
- `styles.css` — стили
- `script.js` — небольшие интерактивные эффекты

## Развёртывание

Сайт размещён через **Cloudflare Pages** и автоматически обновляется при каждом push в эту ветку `main`.
